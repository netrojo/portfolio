# Yousif Magdy (Nega) — Full-Stack Developer Portfolio

Personal developer portfolio & landing page — pure **HTML, CSS & JavaScript**. No frameworks, no build tools.

## Features

- Dark modern UI with gradient accents
- Animated hero with typing effect
- Live project showcase (real projects from `/coding`)
- **Live demo**: Cafe POS runs on `http://localhost:4321`
- Custom SVG favicon
- Fully responsive (mobile hamburger menu)
- Scroll-reveal animations + animated counters
- Cursor glow effect
